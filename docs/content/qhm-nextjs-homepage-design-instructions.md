## 1. UX Leadership Direction

The client feedback is not asking for a decorative refresh. It asks for a stronger **premium legal-firm experience**. The current website content is useful, but the presentation must move from a static brochure into a more dynamic, international-standard homepage.

The new homepage should communicate:

- Saudi legal-market credibility
- Full-service legal capability
- Bilingual / international client readiness
- Riyadh and Jeddah presence
- Practical, innovative legal solutions
- Thought leadership through legal updates and publications
- Premium, calm, confident interface quality

The design should feel high-end, restrained, and editorial. Avoid making it flashy, overly animated, or template-like.

## 3. Benchmark Lessons From Reference Firms

### 3.1 Khoshaim lesson

Khoshaim’s UX is useful for QHM because it shows how a Saudi law firm can feel structured, serious, and premium. It uses clear legal-sector navigation, Arabic language access, modular grids, progressive disclosure, arrow cues, sliders, and structured office/footer information.

Apply to QHM:

- Add Arabic toggle readiness.
- Use numbered or indexed expertise cards.
- Keep interactions subtle and professional.
- Use progressive disclosure instead of showing everything at once.
- Treat Riyadh and Jeddah as credibility assets.

### 3.2 Latham & Watkins lesson

Latham’s design is evidence-based. It uses cards, achievements, deal/news streams, rankings, and insights to prove capability instead of relying only on broad marketing language.

Apply to QHM:

- Convert publications into premium insight cards.
- Add proof modules when available: awards, recognitions, clients served, offices, sectors, experience.
- Make the homepage feel like an active legal-intelligence hub, not a frozen profile.

### 3.3 Clyde & Co lesson

Clyde & Co is research-led and content-heavy but still structured. Its site uses expertise grids, reports, search, popular topics, and clear categorization.

Apply to QHM:

- Make Saudi legal updates a homepage strength.
- Group practice areas by sector or legal need.
- Consider a search entry point for insights later.
- Use clean cards and spacing to manage information density.

### 3.4 Hogan Lovells lesson

Hogan Lovells is media-forward and dynamic. It uses large visuals, storytelling cards, and “we can help you” pathways.

Apply to QHM:

- Use professional office footage/headshots later as hero and section visuals.
- Add interactive pathways such as “We help clients: Establish, Operate, Protect, Resolve, Grow.”
- Use controlled hover and carousel interactions.

## 9. Header Requirements

The header is critical because the client specifically wants the site to feel more premium and less static.

Required behavior:

- Sticky header
- Transparent/glass state over hero
- Solid state after scroll
- Logo scales from larger initial state to smaller sticky state
- Desktop nav with clear spacing
- Mobile full-screen drawer menu
- Arabic toggle placeholder
- Search icon placeholder if insights/search will be added

Do not use a thick bottom border. If separation is needed, use soft blur, shadow, or background opacity.

---

## 10. Motion Rules

Use Framer Motion or CSS transitions.

Motion should be:

- Subtle
- Slow
- Professional
- Consistent
- Accessible

Recommended:

- Hero text reveal: 700–900ms
- Section reveal: 500–700ms
- Card hover lift: 2–6px
- Image reveal mask: 800–1000ms
- Header background transition: 250–350ms

Avoid:

- Bouncy easing
- Continuous floating animations
- Random animated icons
- Fast parallax
- Excessive scroll-triggered effects

Add reduced motion support:

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 11. Typography Direction

Use a serious editorial typography system.

Recommended pairing:

- Display/headings: a refined serif or premium display font
- Body/UI: clean modern sans-serif

Example hierarchy:

```txt
Hero heading: clamp(48px, 8vw, 112px)
Section heading: clamp(36px, 5vw, 72px)
Card heading: 22px–32px
Body: 16px–18px
Nav: 14px–15px
Eyebrow labels: 11px–13px uppercase/tracked
```

Do not use too many font weights. Use spacing, size, and contrast for hierarchy.

## 13. Responsive Design Rules

Mobile must not feel like an afterthought.

Requirements:

- Hero should be strong on mobile, not just stacked text.
- Logo must never crop or overflow.
- Mobile menu should be full-screen and premium.
- Practice areas should become accordions or horizontal scroll cards.
- Insight cards should be swipeable or stacked with clear spacing.
- Contact form fields must be large and easy to tap.
- Avoid tiny text under 14px.
- Avoid animation that causes layout shift.
